# APK Install Error Decoder

A small, privacy-first browser tool for interpreting six common Android `INSTALL_FAILED_*` package-manager results.

**Live tool:** https://apk-install-error-decoder.pages.dev/

## Features

- Paste an ADB installation result or select an error code.
- Get a concise explanation and non-destructive first checks.
- No account, API, upload, analytics, cookies, external fonts, or third-party scripts.
- All parsing stays in the browser.
- Includes links to the relevant Android and AOSP documentation.

## Source

The application is static HTML, CSS, and JavaScript. The production files in this repository are the files served by the live tool.
